# One-Sentence Absurd Invention Pitch

A single-sentence pitch for a ridiculous invention that fixes a tiny
everyday annoyance: a toothbrush that gossips about your midnight snacking
to your dentist in real time, so fear finally does the flossing for you.

`main.py` (Python 3, stdlib only) writes the pitch to `/output/entry.txt`
by default, or to `$OUTPUT_PATH` when set. Deterministic — same output
every run, no randomness, no network.

Entry for the make.fun competition
[One-Sentence Absurd Invention Pitch](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a).
